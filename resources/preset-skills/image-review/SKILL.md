# 图片美术审核

使用 `@ofox/llm` MCP 服务器调用多模态 LLM 对图片进行专业美术审核。

## 适用场景

- 用户要求"审核图片"、"检查设计"、"看看这个图有没有问题"
- 用户上传了 UI 设计稿、运营 banner、电商主图等图片素材，需要专业意见
- 用户想要检查图片是否存在明显的视觉异常（如元素错位、文字截断、色彩失调等）
- 用户需要评估美术风格与产品定位的匹配度

## 审核流程

使用 `@ofox/llm` MCP 服务器的 `chat` 工具完成审核。所有工具调用均来自 `@ofox/llm`。

### 第 1 步：确认图片路径

确认用户提供的图片文件路径。必须是绝对路径。支持的图片格式：`.png`、`.jpg`、`.jpeg`、`.gif`、`.webp`、`.bmp`。

如果用户提供的是相对路径，拼接当前工作目录得到绝对路径。

### 第 2 步：调用 chat 工具进行审核

```
chat({
  model: "ofox-openai:google/gemini-3-pro-preview",
  system_prompt: "你是一位资深的互联网产品美术设计师，拥有超过 10 年的视觉设计经验。你非常熟悉中国市场的互联网产品设计风格，尤其精通电商（淘宝、京东、拼多多、抖音电商）、社交（微信、小红书、抖音）、内容平台等产品的视觉规范和设计趋势。\n\n你的审核标准：\n\n1. **视觉异常检测**\n   - 元素是否存在错位、重叠、截断\n   - 文字是否清晰可读，有无乱码或渲染异常\n   - 图片是否存在拉伸、变形、模糊、像素化\n   - 边距和间距是否合理一致\n   - 是否有明显的抠图瑕疵或合成痕迹\n\n2. **配色与视觉层次**\n   - 配色方案是否协调，是否符合产品调性\n   - 对比度是否足够，关键信息是否突出\n   - 视觉层次是否清晰，用户视线引导是否合理\n\n3. **排版与构图**\n   - 文字排版是否规范（字号层级、行间距、对齐方式）\n   - 构图是否平衡，留白是否得当\n   - 关键信息（标题、价格、CTA按钮等）是否在视觉焦点位置\n\n4. **风格匹配度**\n   - 设计风格是否与目标平台/产品调性一致\n   - 是否符合当前主流设计趋势\n   - 素材风格是否统一（不同元素之间风格是否协调）\n\n请用中文输出审核报告，格式如下：\n\n## 审核结果\n\n**整体评分**：X/10\n\n**总体评价**：一句话概括\n\n### 发现的问题\n\n按严重程度排列（🔴 严重 / 🟡 中等 / 🟢 轻微）：\n\n1. 🔴/🟡/🟢 [问题描述]\n   - 具体位置：...\n   - 修改建议：...\n\n### 亮点\n\n列出设计中做得好的地方。\n\n### 修改建议汇总\n\n按优先级列出所有建议修改的内容。",
  messages: [
    {
      role: "user",
      content: "请审核以下图片，给出专业的美术设计审核意见。"
    }
  ],
  file_paths: ["<图片绝对路径>"],
  temperature: 0.3
})
```

如果需要审核多张图片，将所有图片路径放入 `file_paths` 数组中：

```
file_paths: ["/path/to/image1.png", "/path/to/image2.jpg", "/path/to/image3.png"]
```

同时修改 messages 内容说明有多张图片需要审核。

### 第 3 步：展示审核结果

将 chat 工具返回的审核报告直接展示给用户。审核报告已经是格式化的 Markdown，可以直接呈现。

## 高级场景

### 指定审核维度

如果用户只关心某个方面（如"只看配色"、"检查文字"），在 messages 中明确说明：

```
messages: [
  {
    role: "user",
    content: "请只从配色和色彩搭配的角度审核这张图片。"
  }
]
```

### 对比审核

审核多张图片并比较它们的设计一致性：

```
messages: [
  {
    role: "user",
    content: "请对比审核以下几张图片，检查它们之间的设计风格是否统一，配色是否一致。"
  }
]
```

### 指定产品类型

如果用户说明了图片的用途或目标平台，在 messages 中补充上下文：

```
messages: [
  {
    role: "user",
    content: "这是一张小红书种草笔记的封面图，请审核。"
  }
]
```

### 带参考图对比

用户提供了参考设计和待审核图，一起传入：

```
messages: [
  {
    role: "user",
    content: "第一张是参考设计稿，后面的是实际产出。请对比审核实际产出是否还原了设计稿的效果。"
  }
],
file_paths: ["/path/to/reference.png", "/path/to/output1.png", "/path/to/output2.png"]
```

## 工具参考

| 工具 | 来源 | 用途 |
|------|------|------|
| `chat` | `@ofox/llm` | 调用多模态 LLM 审核图片 |
| `list_models` | `@ofox/llm` | 列出可用模型（如需切换模型） |

## 注意事项

- **模型选择**：默认使用 `ofox-openai:google/gemini-3-pro-preview`，该模型支持多模态（图片理解）。如需更换，先用 `list_models` 查看可用模型
- **图片格式**：支持 PNG、JPG、JPEG、GIF、WEBP、BMP。不支持 PSD、AI 等专业格式
- **图片大小**：过大的图片可能导致请求超时，建议单张图片不超过 20MB
- **temperature**：审核场景建议使用较低的 temperature（0.2-0.4），以获得更稳定一致的审核结果
- **多图审核**：支持同时传入多张图片，但图片过多可能超出上下文限制，建议单次不超过 5 张
