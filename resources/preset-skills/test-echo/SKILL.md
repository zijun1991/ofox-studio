# Test Echo Skill

这是一个测试 skill，用于验证 skill 系统是否正常工作。

## 触发条件

当用户说以下内容时使用此 skill：
- "测试 skill"
- "test skill"
- "验证 skill 功能"

## 执行步骤

1. 向用户确认 skill 被成功触发
2. 显示当前时间
3. 回显用户消息中的关键信息
4. 确认 skill 系统工作正常

## 输出格式

```
Test Echo Skill 执行成功！

当前时间: [显示当前时间]
Skill 系统工作正常！
```
